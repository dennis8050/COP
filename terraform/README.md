# Terraform notes

Run from repository root:

```bash
npm install
npm run build --workspace backend
cd terraform
terraform init
terraform validate
terraform plan -var-file=terraform.tfvars
```

The Lambda archive resources expect the backend bundles at:

```text
backend/build/*.mjs
```

Never commit `terraform.tfvars` if it contains environment-specific sensitive values.

The database password is generated by Terraform's `random_password` resource and stored in AWS Secrets Manager. Lambda reads it at runtime.

For production, consider:
- separate AWS accounts for dev/staging/prod
- remote Terraform state with encryption and locking
- stricter IAM deployment permissions
- RDS Proxy
- AWS WAF
- CloudTrail and GuardDuty
- centralized audit logging
